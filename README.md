# python-basics

研一上学期（2026 年秋）Python 基础练习代码存档，按周归档。

## 目录结构

| 目录 | 主题 | 主要内容 |
|---|---|---|
| `W1/` | Python 入门 | 求和、找最大值、冒泡排序、BMI 计算器、奇偶判断、温度转换 |
| `W2/` | 数据容器与文件处理 | 字符串 / 列表 / 字典 / 元组 / 列表推导式；词频统计（雏形 → 加深 → 多版本迭代）；LeetCode 练习 |
| `W3/` | 正则表达式与异常处理 | 正则表达式（邮箱 / IPv4 校验）、`collections.Counter`、文件读写与异常处理 |

## 目录内的约定

- **`errors/`** —— 保存**故意写错并复现**的版本，用于记录踩坑过程，**不是废弃代码**。
  - 例：`error1_文件路径错导致运行失败.py` / `error2_文件路径修改不完全.py` / `error3_输出写进输入目录.py`
- **`resource/`** —— 练习用的输入数据（文本样本、停用词表、日志样本），不是程序输出。
- 文件名使用中文，与当周的具体任务对应。

## 环境

- Python 3.13
- 以标准库为主，未引入第三方依赖
